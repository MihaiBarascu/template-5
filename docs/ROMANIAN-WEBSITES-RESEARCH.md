# Romanian Business Websites Research

## Summary of Analyzed Websites

Research conducted December 2025 to understand what features and widgets are popular on Romanian business websites.

---

- Dark brown/burgundy theme with gold accents
- Professional, premium feel
- Multiple locations showcase

### Key Features
- **Hero**: Full-width image with overlay

## Common Patterns Identified

### Must-Have Widgets (Present on 80%+ sites)
1. **Cookie Consent Banner** - GDPR requirement
2. **Floating Phone/WhatsApp Button** - Quick contact
3. **Social Media Links** - Facebook, Instagram, TikTok
4. **Google Maps Integration** - Location finder

### High-Priority Features (Present on 60%+ sites)
1. **Online Booking System** - Internal or external (mero.ro, setmore.com)
2. **Testimonials/Reviews** - Often carousel format
3. **Team Section** - Staff photos and credentials
4. **Service Cards** - With icons and descriptions
5. **Photo Gallery** - Before/after or portfolio

### Medium-Priority Features (Present on 40%+ sites)
1. **Multiple Locations Support** - Cards per location
2. **Promotional Banners** - Special offers
3. **ANPC Compliance Badges** - For Romanian businesses
4. **Mobile App Links** - If they have an app
5. **Facebook Page Embed** - Live feed widget

### Design Trends

#### Color Schemes
- **Barbershops**: Dark theme (black/dark brown) + gold/orange accents
- **Dental Clinics**: Light theme (white) + blue/teal accents
- **Beauty Salons**: Light theme + pink/purple accents
- **Restaurants**: Warm theme + burgundy/gold accents

#### Typography
- Serif fonts for headings (premium feel)
- Sans-serif for body text
- Large, bold headlines

#### Layout Patterns
- Full-width hero sections
- Card-based service/team displays
- Grid galleries (masonry popular)
- Sticky header with CTA button

## Recommendations for Our Template

### New Blocks to Create

#### 1. BeforeAfterSlider (HIGH PRIORITY)
- Interactive before/after image comparison
- Popular for barbershops, dental, beauty
- Drag-to-reveal interaction

#### 2. BookingForm Block (HIGH PRIORITY)
- Inline booking form (not just external link)
- Service, date, time, contact fields
- Integration-ready design

#### 3. LocationsGrid Block (MEDIUM PRIORITY)
- Multiple location cards
- Each with address, phone, hours, map link
- Photo per location

#### 4. BackToTop Component (LOW PRIORITY)
- Floating button after scroll
- Smooth scroll animation

### Block Enhancements

#### Hero
- Add video background option
- Add parallax effect option
- Floating social icons option

#### Team
- Add social media links per member
- Add "Book with [name]" button
- Add credentials/certifications list

#### Testimonials
- Add initials avatar fallback
- Add carousel pagination dots
- Add "From Facebook" badge option

#### Footer
- Add ANPC badges section
- Add mobile app download links
- Add Facebook page embed option

### Global Improvements

#### Widgets to Add
1. **ANPC Badges Widget** - Required for Romanian e-commerce
2. **Mobile App Links Widget** - App Store + Google Play buttons
3. **Facebook Page Widget** - Embedded feed

#### Design System Updates
- Barbershop theme: Dark + Gold (#C9A227)
- Dental theme: White + Teal (#00A0B0)
- Ensure premium serif fonts for headings
