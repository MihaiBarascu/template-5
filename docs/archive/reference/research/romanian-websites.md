# Romanian Business Websites Research

> **Scop:** Analiza site-uri profesionale din Romania pentru inspiratie design

---

## Site-uri Analizate

### 1. House of Barbers (houseofbarbers.ro)
- Dark brown/burgundy theme cu gold accents
- Multiple locations showcase
- Integration cu mero.ro pentru booking
- Promotional banners

### 2. The Barber (thebarber.ro)
- Clean white/light theme cu red accents
- Multiple location cards
- Integration cu setmore.com

### 3. Original Barber Shop (barber.ro)
- Dark theme cu gold/orange accents
- INLINE booking form pe homepage
- Testimonials carousel (10 slides)
- Mobile app links

### 4. Dentessence (dentessence.ro)
- Clean white cu pink/purple accents
- Doctor cards cu credentials
- Cabinet gallery

---

## Pattern-uri Comune Identificate

### Must-Have (80%+ site-uri)
1. Cookie Consent Banner (GDPR)
2. Floating Phone/WhatsApp Button
3. Social Media Links
4. Google Maps Integration

### Frecvente (50%+ site-uri)
1. External Booking Integration
2. Testimonials Section
3. Team/Staff Cards
4. Service Cards cu preturi

### Nice-to-Have
1. Video Background
2. Before/After Slider
3. Instagram Feed
4. Mobile App Links
5. ANPC Badges (SAL/SOL)
