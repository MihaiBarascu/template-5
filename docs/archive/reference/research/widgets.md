# Widget Research - Analiza Comparativa

> **Scop:** Identificarea widget-urilor necesare pentru diferite nise

---

## Problema Identificata

Site-urile noastre sunt **prea similare**. Structura generica:
- Hero simplu
- Services grid identic
- Stats bar
- Team cards
- Testimonials carousel
- FAQ accordion
- CTA section

**Nu reflecta specificul fiecarui business.**

---

## Widget-uri Universale (Toate Business-urile)

| Widget | Descriere |
|--------|-----------|
| Hero | Banner principal cu CTA |
| Services | Prezentare servicii |
| Team | Echipa/Staff |
| Testimonials | Recenzii clienti |
| FAQ | Intrebari frecvente |
| Contact | Formular + Info |
| Gallery | Galerie imagini |
| Map | Google Maps |
