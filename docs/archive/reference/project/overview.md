# Universal Business Website Platform - Overview

---

## Viziune

O platforma Payload CMS unificata din care se pot crea site-uri pentru ORICE tip de afacere prin rularea unui singur seeder.

---

## Workflow

```
1. Clonezi proiectul
2. Rulezi: pnpm seed:frizerie (sau dentist, avocat, etc.)
3. Site-ul e gata cu design, continut demo si imagini
4. Personalizezi din admin panel
5. Deploy
```
