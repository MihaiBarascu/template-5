# Widget Research - Analiza Comparativa Site-uri Romania

## PROBLEMA IDENTIFICATA

Site-urile noastre (a-h.multiwebsite.org) sunt **prea similare** intre ele. Toate au aceeasi structura:
- Hero simplu cu text + butoane
- Services grid identic
- Stats bar (numere)
- Team cards
- Testimonials carousel
- FAQ accordion
- CTA section
- Footer standard

**Aceasta structura este prea generica** si nu reflecta specificul fiecarui business.

---

## ANALIZA COMPARATIVA

### SITE-URI NOASTRE vs SITE-URI PROFESIONALE

| Aspect | Site-urile noastre | Site-uri profesionale |
|--------|-------------------|----------------------|
| Hero | Text simplu + 2 butoane | Video background, slider complex, forme integrate |
| Servicii | Grid uniform | Carduri cu hover effects, iconite animate, categorii |
| Contact | Doar in footer | WhatsApp floating, live chat, formular inline |
| Galerie | Grid static | Lightbox, carousel, video embeds |
| Oferte | Lipseste | Banner promotional, countdown timer, oferte lunii |
| Blog | Lipseste | Articole recente, categorii |
| Locatii | Doar adresa text | Harta Google integrata, selector orase |
| Trust | Stats simple | Certificari, logo parteneri, premii |
| Video | Lipseste | YouTube embed, video testimoniale |

## IMPLEMENTARE PAYLOAD BLOCKS

### Structura recomandata pentru fiecare block:

```
src/blocks/
├── common/                    # Blocuri comune
│   ├── WhatsAppFloat/
│   ├── GoogleMap/
│   ├── VideoEmbed/
│   ├── ImageLightbox/        # PRIORITATE CRITICA
│   ├── Newsletter/
│   └── SocialProof/
├── booking/                   # Blocuri programare
│   ├── BookingInline/
│   ├── AppointmentScheduler/
│   └── ReservationForm/
├── commerce/                  # Blocuri eCommerce
│   ├── ProductCarousel/
│   ├── PromoBanner/
│   └── PriceCalculator/
├── content/                   # Blocuri continut
│   ├── BlogPreview/
│   ├── VideoTabs/
│   └── BeforeAfterSlider/
└── trust/                     # Blocuri incredere
    ├── CertificationsBar/
    ├── ClientLogos/
    └── SuccessStats/
```

### Reguli implementare:

1. **Fiecare block** are `config.ts` + `Component.tsx`
2. **Foloseste `interfaceName`** in config pentru tipuri generate
3. **Import tipuri** din `@/payload-types` - NICIODATA `any`
4. **CSS Variables** pentru culori - permite tematizare
5. **Responsive design** - mobile-first approach
6. **Accessibilitate** - ARIA labels, keyboard navigation

## SEEDERE UPDATE

Dupa implementare, fiecare seeder trebuie actualizat pentru a include widget-uri specifice:

```typescript
// seed/businesses/frizerie.ts
export const frizerieSeed = {
  pages: {
    home: {
      blocks: [
        { blockType: 'hero', ... },
        { blockType: 'priceListDotted', ... },  // NOU
        { blockType: 'videoEmbed', ... },        // NOU
        { blockType: 'beforeAfterSlider', ... }, // NOU
        { blockType: 'team', ... },
        { blockType: 'testimonials', ... },
        { blockType: 'bookingInline', ... },     // NOU
        { blockType: 'instagramFeed', ... },     // NOU
      ]
    }
  },
  globals: {
    floatingWidgets: ['whatsappFloat']  // NOU
  }
}
```

## CONCLUZII

1. **Site-urile noastre sunt prea generice** - aceeasi structura pentru toate
2. **Site-urile profesionale au widget-uri specifice** - fiecare nisa are nevoi diferite
3. **Trebuie implementate 20+ blocuri noi** - vezi lista de prioritati
4. **Seedere trebuie actualizate** - fiecare business cu widget-uri specifice
5. **ImageLightbox este CRITICA** - utilizatorii nu pot vizualiza imaginile
