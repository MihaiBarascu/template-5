# Design Patterns per Nișă - Cercetare Site-uri România

## Sumarul Cercetării

Am analizat 90+ screenshot-uri de la site-uri profesionale românești din 8 nișe diferite pentru a identifica pattern-uri de design specifice fiecărei industrii.

---

## 1. FRIZERIE / BARBERSHOP

### Site-uri analizate:
- barber.ro, houseofbarbers.ro, thebarber.ro, cutlassicbarbershop.ro

### Widget-uri specifice identificate:

| Widget | Descriere | Prioritate |
|--------|-----------|------------|
| **PriceListDotted** | Listă prețuri cu linie punctată între serviciu și preț | CRITICĂ |
| **BookingWidget** | Programare online integrată (Fresha, Booksy) | CRITICĂ |
| **BeforeAfterSlider** | Comparație înainte/după pentru tunsori | ÎNALTĂ |
| **BarberCards** | Carduri frizeri cu specialități și social links | ÎNALTĂ |
| **InstagramFeed** | Feed Instagram cu lucrări recente | MEDIE |
| **ProductsCarousel** | Produse styling recomandate | MEDIE |

### Elemente vizuale caracteristice:
- **Culori:** Negru, Auriu, Roșu închis, Maro vintage
- **Fonturi:** Serif pentru titluri (vintage feel), Sans-serif pentru body
- **Imagini:** Fotografii B&W sau cu tonuri calde, close-ups tunsori
- **Layout:** Dark theme predominant, accent pe atmosfera masculină

### Pattern-uri UX:
- Buton "Programează-te" prominent în header
- WhatsApp floating pentru programări rapide
- Galerie cu lucrări recente
- Secțiune echipă cu specializări individuale

## STRUCTURA SEEDERE ACTUALIZATĂ

Fiecare seeder trebuie să includă blocuri specifice nișei:

```typescript
// Exemplu: seed/businesses/frizerie.ts
export const frizerieSeed = {
  pages: {
    home: {
      blocks: [
        { blockType: 'hero', variant: 'dark' },
        { blockType: 'priceListDotted', ... },
        { blockType: 'barberCards', ... },
        { blockType: 'gallery', variant: 'grid' },
        { blockType: 'testimonials', ... },
        { blockType: 'faq', ... },
        { blockType: 'contactForm', ... },
      ]
    }
  },
  globals: {
    floatingWidgets: ['whatsappFloat'],
    theme: {
      primary: '#000000',
      secondary: '#C9A227',
      accent: '#8B0000'
    }
  }
}
```

## CONCLUZII

1. **Site-urile profesionale românești au pattern-uri clare per nișă**
2. **WhatsApp floating este omniprezent** - trebuie implementat ca prioritate
3. **Fiecare nișă are 3-5 widget-uri specifice** care o diferențiază
4. **Statistici animate și social proof** sunt foarte populare
5. **Booking/Programări** sunt critice pentru servicii
6. **Countdown timers și badge-uri** sunt esențiale pentru ecommerce
